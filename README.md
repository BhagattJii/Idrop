# iDrop

Fast, privacy-friendly file sharing app for Android. Share files quickly between nearby devices over your local Wi-Fi network.

Based on [TrebleShot](https://github.com/trebleshot/android), managed and upgraded by [BhagattJii](https://github.com/BhagattJii).
